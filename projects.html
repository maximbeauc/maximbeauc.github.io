Design Team · Jun 2026 – Present

Waterloo Rocketry — Controls Subteam

Waterloo Rocketry is the University of Waterloo's student rocketry design team. On the Controls Subteam, I work on the firmware for the rocket's canards — the small fins near the nose that help control it in flight — with a focus on making that system reliable, observable, and well tested.

  • Led the redesign of the error log system, encoding entries from 128 to 32 bytes and aggregating repeated logs so 400 Hz tasks can't flood it.
  • Designed FreeRTOS motor telemetry in C, sending current, angle, and temperature over CAN at frequencies set by the flight state.
  • Wrote C++ unit tests in Docker for the canard fin actuation firmware on an STM32H733, using GoogleTest and the Fake Function Framework (FFF) to simulate successful and unsuccessful UART, CAN, and I2C transmissions.

MTE 100 Course Project · Nov 2025

Autonomous Tic-Tac-Toe Robot

Designed and built a fully autonomous robot that plays Tic-Tac-Toe against a human opponent — with a 0% loss rate across 50 games. The project spanned the full engineering pipeline: mechanical design in SolidWorks, 3D-printed fabrication of custom components, motor and sensor integration, and C++ game logic that decides the robot's next move.

  • Integrated colour sensing to detect the board state and motor control to autonomously place the pieces chosen by the game logic, with consistent, accurate placement.
  • Modeled and 3D printed components in SolidWorks, including the game pieces, game board, and motor mount.
